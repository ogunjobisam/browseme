Extensions

Load Chrome extensions from a folder, a .zip, or a .crx.

How loading works

Extensions run in Chromium's own extension system. Store downloads arrive as .crx files, which are unpacked here before loading. Manifest V2 and V3 both load, though some newer APIs are not implemented by Electron — an extension that depends on one will load but misbehave, so check its features after installing.

Extensions are off in private mode by default. Turn one on there only if you trust it with that browsing, since it will see those pages.
